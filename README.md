# Apex Ludo 1.1 (beta)

A clean-room, fully offline, ad-free Ludo built from scratch in Kotlin for Android.
No accounts, no trackers, no network permission — the only permission the app asks for
is `VIBRATE`, and every bot runs on your phone's own CPU.

- **Version:** 1.1 (beta), versionCode 2
- **Platform:** Android 7.0+ (API 24), target API 34
- **Size:** ~825 KB release APK
- **License:** MIT

---

## What it is

Apex Ludo is an original implementation of the classic cross-and-circle board game,
written from the ground up: a deterministic, unit-tested rules engine in pure Kotlin,
and a single hand-drawn hardware-accelerated canvas renderer on top of it.

It is **not** a decompilation, port or asset rip of any existing game. The rules are the
public, traditional rules of Ludo; the code, art, audio and AI in this repository were all
produced for this project.

## Feature highlights

| Area | What you get |
| --- | --- |
| Board | 52-cell ring, 5-cell home columns, 8 safe cells, blockades, exact-roll home |
| Rules | 12 individually switchable rules + 4 presets (Classic, Quick, Battle, Peaceful) |
| Bots | 6 personalities: Balanced, Tactical, Aggressive, Defensive, Adaptive, Grandmaster |
| AI | 3 cooperating agents (board analyst, strategic planner, probability agent) + capped Monte-Carlo rollouts, all on-device |
| Visuals | 6 board themes, 4 board skins, 4 token styles, "Powder Reincarnation" capture effect, shockwave ripples, confetti |
| Audio | 12 synthesized effects + ambient loop, SFX/music buses with independent volume |
| Feel | Contextual haptics, spring-eased overlays, camera shake, animated dice |
| Quality | 10,000-cycle fuzz suite, 200 full-match soak test, per-move invariant checks |
| Extras | Daily streak rewards, statistics, match log, AFK auto-pilot, battery saver, FPS overlay, high-contrast palette, English + Hindi |

## Install

Grab the APK from the latest **GitHub Actions artifact** (`apex-ludo-1.1-beta-apk`), then:

```
adb install -r ApexLudo-1.1-beta-release.apk
```

The release APK is signed with the beta key generated by the CI pipeline, so if you have an
older build installed, uninstall it first.

## Build it yourself

Requirements: JDK 17, Android SDK platform 34 + build-tools 34.0.0.

```bash
./gradlew :app:testDebugUnitTest     # rules, board, AI, 10k-cycle fuzz, 200-match soak
./gradlew :app:assembleDebug         # installable debug APK
./gradlew :app:assembleRelease       # minified release APK (signed if beta-release.jks exists)
```

CI (`.github/workflows/build-apk.yml`) does exactly this on every push: tests first, then a
signed release APK plus a debug APK, both uploaded as artifacts.

## Project layout

```
app/src/main/java/com/apexludo/
├── core/                 # pure Kotlin, zero Android imports, fully unit-tested
│   ├── Board.kt          # 15x15 topology, ring/column indexing, safe-cell masks
│   ├── Rules.kt          # RuleSet + presets
│   ├── GameState.kt      # flat IntArray state, cloning for rollouts, checksums
│   ├── MoveGen.kt        # legal-move generation (captures, blockades, home entry)
│   ├── MatchEngine.kt    # turn FSM, extra turns, triple-six, ranking
│   ├── Rng.kt            # xorshift64* PRNG + dice engine
│   ├── AiEngine.kt       # the three agents + rollout evaluator
│   └── Telemetry.kt      # replay recorder, match log, match factory
└── app/                  # Android layer
    ├── MainActivity.kt   # single activity, programmatic overlays (no XML layouts)
    ├── GameView.kt       # canvas renderer: board, tokens, dice, particles, HUD
    ├── Session.kt        # turn controller, timers, bot scheduling
    ├── Particles.kt      # pooled powder/confetti/shockwave system
    ├── SoundEngine.kt    # SoundPool + MediaPlayer, SFX/music buses
    ├── ThemeDefs.kt      # themes, board skins, token skins
    ├── PerfMonitor.kt    # FPS governor + crash logger
    ├── Prefs.kt          # local settings and stats
    └── Ui.kt             # small programmatic UI kit
```

## Testing

`app/src/test/java/com/apexludo/core/`

* `BoardTest` — ring is contiguous, 52 unique cells, four diagonal corner turns, home columns
  never overlap the ring, safe-cell count, monotonic progress mapping.
* `RulesTest` — yard unlock, exact-roll home, captures, safe cells, blockades (landing and
  passage), stacking, triple-six forfeit, extra turns, ranking, 2-player colour mapping.
* `DiceAndAiTest` — dice range and uniformity (600k rolls), seed determinism, every AI profile
  returns a legal move, rollouts never mutate live state, rollout time budget.
* `StressTest` — 10,000 turn cycles across 8 rule sets with invariant checks after every
  single action, 200 complete matches, crammed-board edge case.

The fuzz suite earned its keep: it caught two real bugs during development — a mixed-stack
capture bug and a seat-index/colour-index mix-up that silently disabled captures in 2-player
games. Both are fixed and pinned by regression tests.

## Honest scope notes

This is a **single-device beta**. Online multiplayer, cloud sync, spectator mode and
downloadable asset bundles are deliberately out of scope for 1.1 — the app has no network
permission at all. `docs/FEATURES.md` lists every planned feature with its real status.
